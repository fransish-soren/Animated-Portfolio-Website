# ✨ Animated Portfolio Website

A modern, responsive, and interactive **developer portfolio website** built with pure **HTML, CSS, and JavaScript**. 
Designed to showcase skills, projects, services, experience, and contact information with smooth animations and a clean professional UI.

## 🚀 Live Preview

🔗 **Live Demo:** `https://your-username.github.io/portfolio/`

## 📌 Features

* 🎨 Modern and clean UI
* 📱 Fully responsive design
* 🌙 Dark / Light mode
* ✨ Smooth scroll animations
* ⌨️ Typing text animation
* 🧭 Sticky animated navigation
* 📂 Animated project portfolio
* 🔍 Project filtering
* 💼 Services section
* 🛠️ Skills with animated progress bars
* 💬 Testimonial slider
* 📧 Contact form validation
* 🔝 Animated back-to-top button
* 📱 Mobile-friendly hamburger menu
* ⚡ Scroll reveal effects

* 🎯 Active navigation highlighting
* ♿ Semantic HTML and accessible controls

## ⚡ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/fransish-soren/animated-portfolio.git
```

### 2. Open the project

```bash
cd animated-portfolio
```

### 3. Run the website

Simply open:

```text
index.html
```

in your browser.

For the best development experience, use **VS Code + Live Server**.

## 🌐 Deploy on GitHub Pages

1. Upload the project to GitHub.
2. Open your repository.
3. Go to **Settings**.
4. Select **Pages**.
5. Choose the `main` branch.
6. Select `/root` as the folder.
7. Click **Save**.

Your portfolio will then be available through your GitHub Pages URL.
